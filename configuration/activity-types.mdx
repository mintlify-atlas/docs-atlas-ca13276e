## Overview

Stratiles supports over 50 different activity types from Strava. You can customize which types appear in your heatmap and widgets, allowing you to focus on the sports and activities that matter most to you.

## Default Selection

By default, Stratiles tracks these activity types:
- Run
- Ride
- Walk
- Trail Run
- Hike
- Wheelchair

These represent the most common distance-based activities on Strava.

## Configuring Activity Types

<Steps>
  <Step title="Open Settings">
    Tap the settings icon in the top right corner of the main heatmap view.
  </Step>
  
  <Step title="Browse Categories">
    Activity types are organized into five categories:
    - Foot Sports
    - Cycling
    - Water Sports
    - Winter Sports
    - Other Sports
  </Step>
  
  <Step title="Select Activities">
    Toggle on the activity types you want to track. You can select as many or as few as you like.
  </Step>
  
  <Step title="Automatic Sync">
    Your changes are saved automatically. The app will refresh your heatmap and widgets to reflect your new selection.
  </Step>
</Steps>

<Info>
When you change your activity type selection, widgets on your home screen automatically update to show only the selected types.
</Info>

## How Activity Matching Works

Stratiles uses Strava's activity type and sport type fields to categorize your activities:

1. **Sport Type First**: Strava's sport type field (more specific) is checked first
2. **Fallback to Type**: If sport type is not available, the general activity type is used
3. **Normalized Matching**: Types are matched case-insensitively with underscores removed
4. **Special Cases**: Some activity types match multiple Strava sport types (e.g., Rowing matches both "rowing" and "virtualrow")

<Tip>
If an activity doesn't appear in your heatmap, verify that you've enabled its activity type in Settings. Some activities may use specific sport types that map to Stratiles categories.
</Tip>

## Filtering Behavior

- **Empty Selection**: If you deselect all activity types, Stratiles automatically reverts to the default selection (Run)
- **Retroactive Filtering**: Changing your selection filters your entire activity history, not just new activities
- **Widget Updates**: All home screen widgets automatically update when you change activity types
- **Data Fetching**: Stratiles fetches all your activities from Strava and filters them locally based on your selection

<Warning>
Stratiles fetches up to 800 recent activities (8 pages × 100 activities per page). If you have more activities than this limit, older activities may not appear.
</Warning>

## Technical Details

- Activity type preferences are stored in UserDefaults using App Groups
- The selected types are shared between the main app and widgets
- Changes trigger an immediate widget timeline reload via `WidgetCenter.shared.reloadAllTimelines()`
- Activity filtering happens client-side after fetching from the Strava API

<Info>
Activity type settings are stored locally on your device and sync automatically between the main app and all widgets.
</Info>
